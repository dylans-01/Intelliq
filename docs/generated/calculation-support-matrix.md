# Calculation support matrix (generated)

Generated by `apps/api/scripts/gen_compat_matrix.py` from the function catalogue
(`intelliq/calc/functions.py`) and the executable cases in
`tests/integration/test_function_compatibility.py`. Every listed function is executed
against DuckDB in CI; PostgreSQL equivalence is covered by the connector contract suite.

Status: **Tested** = executed with expected values derived from Tableau's documented semantics.
**Tested · Tableau validation pending** = behaviour chosen where Tableau's documentation is
ambiguous; must be confirmed against real Tableau output (see docs/07-validation.md).
